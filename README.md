# Детектор на текст, писан от ИИ (с обяснение защо)

Класификатор, който приема текст на български и връща вероятност дали е писан от
човек или от ИИ, заедно с обяснение кои признаци са натежали към решението.

> **Учебен инструмент, не доказателство.** Моделите грешат — особено при кратки
> текстове, при жанрове, различни от обучаващите данни, и при ИИ модели, които не са
> виждали в обучението. Не използвай резултата, за да обвиниш някого.

## Как работи

1. **Данни** (`data/`)
   - Човешки текстове: въведенията на статии от българската Уикипедия по 60 теми
     (`data/topics_bg.txt`; 53 имат достатъчно дълго въведение). Свалят се с пакетни
     заявки (20 статии на заявка) — заявка на статия бързо води до HTTP 429.
   - ИИ текстове: генерирани на **същите теми** и с **подобна дължина**, за да
     учи моделът стил, а не тема или дължина.
   - Референтен корпус: 200 въведения на случайни статии за n-грамния
     езиков модел, използван за признака „перплексити“.
   - Формат: CSV с колони `text`, `label` (0 = човек, 1 = ИИ), `topic`, `source`, `model`.
   - Train/test 80/20 с баланс на класовете. **Разделянето е по тема** — една тема е
     или само в train, или само в test, иначе TF-IDF моделът „запомня“ темите.

2. **Признаци** (`detector/features.py`) — сърцето на проекта. Всички са
   нормализирани спрямо дължината:

   | Група | Признаци |
   |---|---|
   | Лексикално разнообразие | MATTR (плъзгащо се съотношение уникални/общо думи), дял на думите, срещнати веднъж |
   | Изречения | средна дължина, **стандартно отклонение** (ИИ текстът е по-еднороден) |
   | Burstiness | B = (σ−μ)/(σ+μ) за дължината на изреченията и за разстоянията между повторенията на думите |
   | Думи | средна дължина и разсейване |
   | Пунктуация | запетаи, „:“ и „;“, тирета, скоби, кавички, „!“ и „?“ — на 100 думи |
   | Честоти | числа на 100 думи, дял служебни думи, клиширани „ИИ изрази“ („също така“, „ключова роля“…) |
   | Предсказуемост | бита/символ под символен 4-грамен модел (Witten–Bell) + разсейването ѝ по изречения |

   Перплексити признакът е „бедна версия“ на това, което правят инструменти като
   GPTZero с невронен езиков модел: n-грамният модел не изисква PyTorch, обяснява се
   лесно и е достатъчен за учебни цели.

3. **Модели** (`scripts/train.py`)
   - `features_lr` — StandardScaler + Logistic Regression върху признаците. **Основният
     модел**: линеен е, значи всяко решение се разлага точно на приноси на признаците.
   - `features_lr_no_genre` — същото, но без скобите, числата и кавичките (вж. аблацията).
   - `features_rf` — Random Forest върху същите признаци.
   - `tfidf_lr` — TF-IDF на символни 2–4-грами + Logistic Regression върху суровия
     текст (baseline без ръчни признаци).

4. **Оценка** — accuracy, precision, recall, F1, ROC AUC, матрица на объркване,
   5-кратна крос-валидация по теми, анализ на грешките и тест върху **модел, който не е
   бил в обучението** (`--holdout-model`). Освен това:
   - **аблация** — CV F1 без всяка група признаци и само с нея;
   - **калибриране** — Platt scaling върху out-of-fold логитите, с Brier score и ECE;
   - **крива на ученето** — F1 спрямо броя обучаващи текстове
     ([`reports/learning_curve.svg`](reports/learning_curve.svg)).

   Всичко се записва в [`reports/report.md`](reports/report.md) и `reports/metrics.json`.

5. **Обяснимост** — за всеки текст приносът на признак *i* към логита е
   `coefᵢ · zᵢ`, където `zᵢ` е стандартизираната стойност. Топ признаците се показват
   с човешко обяснение и със сравнение спрямо средното за човешки и ИИ текстове
   („изреченията са необичайно равномерни по дължина (σ = 3,1 при средно 7,8 за
   човешки текстове)“).

6. **Приложение** — FastAPI (`app/main.py`) + HTML/CSS/JS без външни библиотеки.
   Вход вляво, резултат вдясно (една колона на телефон). Резултатът показва gauge с
   калибрираната вероятност и четири таба: **Защо** (топ признаците с диаграма на приноса
   към човек/ИИ), **По изречения** (графика на „човешкост“ по дължината на текста и
   оцветени изречения), **Признаци** (всички 19 спрямо средните) и **Модели** (сравнение
   между четирите модела). Има бутони с примери от тестовото множество и светла/тъмна тема.

```bash
python -m venv .venv
```

```bash

```

Целият процес отнема около минута (свалянето е най-бавно):

```bash
.venv\Scripts\python scripts/collect_human.py --contact you@example.com
```

```bash
.venv\Scripts\python scripts/build_dataset.py
```

```bash
.venv\Scripts\python scripts/train.py
```

```bash
.venv\Scripts\uvicorn app.main:app --reload
```

и отвори <http://127.0.0.1:8000>. API-то е и директно достъпно:

```bash
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d "{\"text\": \"...\"}"
```

Отговор (съкратен):

```json
{
  "ai_probability": 0.91,
  "verdict": "Вероятно е писан от ИИ",
  "model_probabilities": {"features_lr": 0.91, "features_rf": 0.84, "tfidf_lr": 0.77},
  "top_features": [{"label": "Числа на 100 думи", "toward": "ai", "contribution": 1.4,
                    "text": "почти няма числа и дати — общи формулировки (0.90 при средно 4.10 за човешки и 1.20 за ИИ текстове)"}],
  "segments": [{"sentence": "...", "ai_probability": 0.88}],
  "warnings": []
}
```

`collect_human.py` спазва `Retry-After` на Уикипедия. Политиката на Уикимедия иска
контакт в User-Agent (`--contact`) — без него заявките се ограничават по-агресивно.

## Данни за ИИ текстовете

В репото има `data/ai_seed.csv` — **60 текста, написани от Claude Opus 5.5 в чат
сесия** по същия промпт, който използва генераторът. Те позволяват всичко да тръгне
веднага, но са от **един модел** и са само 60, така че метриките са ориентировъчни и
тестът с невиждан модел не може да се направи.

За истински корпус с няколко модела:

```bash
set ANTHROPIC_API_KEY=sk-ant-...
```

```bash
.venv\Scripts\python scripts/generate_ai.py
```

```bash
.venv\Scripts\python scripts/build_dataset.py --holdout-model claude-haiku-5-5
```

```bash
.venv\Scripts\python scripts/train.py
```

`generate_ai.py` пише по един текст на тема с Claude Opus 5.5, Sonnet 5.5 и Haiku 5.5
(`--models` за друг избор) и е възобновяем. `--holdout-model` изважда един модел
изцяло от обучението → в отчета се появява „Unseen recall“: какъв дял от неговите
текстове детекторът хваща. Резервни модели при отказ нарочно не са включени: ако
друг модел довърши отговора, етикетът `model` ще е грешен.

Може да добавиш и свои човешки текстове (есета, форуми) като CSV със същите колони:
`build_dataset.py --human data/human.csv data/my_essays.csv`.

## Тестове

```bash
.venv\Scripts\python -m pytest
```

21 теста: разделяне на изречения (съкращения като „г.“, „т.е.“, инициали), признаците,
n-грамния модел и API-то. Един от тях проверява, че сумата от приносите на признаците
плюс свободния член дава точно логита на модела, т.е. че обяснението е вярно.

## Резултати

Seed корпус: 53 човешки + 60 ИИ текста → балансирани 53+53, train 84 / test 22
(разделени по тема). Пълният отчет е в [`reports/report.md`](reports/report.md).

| Модел | CV F1 (5 fold, по теми) | Test accuracy | Precision | Recall | F1 | ROC AUC |
|---|---|---|---|---|---|---|
| Признаци + LR | 0.885 | 0.864 | 0.900 | 0.818 | 0.857 | 0.983 |
| Признаци + RF | 0.874 | 0.955 | 1.000 | 0.909 | 0.952 | 0.959 |
| TF-IDF + LR | 0.882 | 0.955 | 0.917 | 1.000 | 0.957 | 0.975 |

При 22 тестови текста една грешка е ~4,5 пункта accuracy, така че разликите между
моделите са в рамките на шума — крос-валидацията (0.87–0.89 F1 и за трите) е
по-честната оценка. Приложението ползва LR върху признаците, защото решението ѝ се
обяснява точно.

**Какво научи моделът (и защо това е урок):**

- Най-силният признак са **скобите** (1,55 на 100 думи при човешките текстове срещу 0,02
  при ИИ). Това е по-скоро конвенция на Уикипедия — произношение, години, превод в
  скоби — отколкото „човешкост“. Детектор, обучен на друг жанр, няма да го научи.
- Човешките изречения са **по-дълги и по-неравномерни** (σ = 7,9 срещу 5,1 думи) —
  точно хипотезата от Стъпка 2.
- ИИ текстовете имат **по-високо лексикално разнообразие** и почти нямат „:“ и „;“.
- Клишираните „ИИ изрази“ са три пъти по-чести при ИИ (0,46 срещу 0,15 на 100 думи),
  но тежестта им в LR е малка, защото информацията се припокрива с другите признаци.

**Аблация** (CV F1 на LR, 5 fold по теми):

| | CV F1 |
|---|---|
| Всички признаци | 0.885 |
| Без жанровите признаци (скоби, числа, кавички) | 0.846 |
| **Само** жанровите признаци | 0.855 |
| Без групата „Изречения“ | 0.844 |
| Само „Изречения“ | 0.784 |

Само три признака, които описват Уикипедия, а не човека, стигат почти колкото всичките
19. Затова 0.885 надценява колко стилов сигнал има моделът. Без тях пак остават 0.846,
значи истински сигнал има. Най-полезни са дължината и ритъмът на изреченията и
разнообразието на речника. В приложението „Без жанр“ се показва като отделен модел за сравнение.

**Калибриране.** Platt scaling дава P = σ(1.06 · логит − 0.15), т.е. почти нищо не
променя: върху текстове като обучаващите вероятностите на LR вече са честни (ECE 0.12 →
0.12, Brier 0.055). Калибрирането **не** оправя кратките текстове: 12 думи пак дават
~100%, защото са извън разпределението на обучаващите данни. Затова под 40 думи
приложението не дава присъда, а под 80 предупреждава.

**Крива на ученето.** Признаците стигат ~0.8 F1 още при 16 текста и после растат бавно
(0.79 → 0.89). TF-IDF е безполезен при малко данни (0.42–0.65), но расте най-стръмно и
при 66 текста ги догонва. Повече данни ще помогнат най-много на TF-IDF, а на признаците —
по-скоро нови признаци.

**Грешки** (анализът е в отчета): ИИ текстът за „Европейски съюз“ мина за човешки —
има много числа и години и нисък дял уникални думи; въведението на „Кирилица“ мина
за ИИ — няма нито една скоба, а повтарящите се думи („кирилица“) са разпръснати
равномерно из текста.

## Ограничения

- **Не е доказателство.** Вероятност 90% не значи „90% сигурно е ИИ“ — значи, че
  текстът прилича повече на ИИ текстовете от обучението, отколкото на човешките.
- **Кратки текстове** (под ~80 думи): признаците стават шумни; приложението предупреждава.
- **Жанр.** Човешките текстове са енциклопедични. Есе, публицистика, форумен пост или
  художествен текст може да се окаже далеч от двата класа и да бъде класифициран
  произволно. Някои признаци (числа, скоби) отразяват конвенциите на Уикипедия толкова,
  колкото и човешкото писане.
- **Нови модели и промпти.** Детекторът научава стила на моделите в обучението при
  конкретен промпт. Друг модел, друг промпт („пиши разговорно, с грешки“) или
  перифразиране лесно го заблуждават.
- **Малко данни.** Seed корпусът е 60+60 текста; при толкова малко данни отделни
  тестови текстове местят метриките с няколко процента.
- **Обратната страна на грешката.** Хора с много подреден, „учебникарски“ стил —
  включително хора, които пишат на втори език — по-често биват маркирани като ИИ.
